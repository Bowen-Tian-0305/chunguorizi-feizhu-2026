# 部署与运行说明

香港 ECS 提供公网应用，可通过 https://47.238.228.164/ 体验。比赛演示服务保留至2026年12月25日，覆盖赛事初评、终评和奖项公布期。

## 当前云端方案

- Ubuntu 22.04，2核2GB、40GB系统盘；试用抵扣300元已开通。
- 无自备域名：Nginx + Certbot公网IP证书。证书约6天有效，自动续期每12小时检查，模拟续期和实际续期服务执行通过。
- 2026-12-26 00:00（北京时间）自动释放实例和系统盘。
- 应用仅映射127.0.0.1:4173，公网仅80/443。正式发布后HTTPS提供完整应用。
- 无域名部署步骤见 [IP HTTPS部署](../deploy/ip-https.md)。此文件不包含账号凭据、证书私钥或服务器账本。

## 运行能力

服务端提供语音转写、条件提取、截图字段识别、待核事项、单餐修改预览、飞猪体验模式酒店候选、周边餐馆与步行路线。全国城市列表与固定示例不依赖实时模型。示例价格为测试值，公开商品截图为历史快照；菜单、供应与权益仍需按本次日期核对。

## 额度及流量保护

- 两款实际使用模型 qwen3.8-flash 和 qwen-audio-3.1-asr-flash 已开启免费额度用完即停；这是账号下对应模型的共享设置。
- 模型默认全站30次/日，每IP 5次/日及小时；语音转写、需求分析、截图提取、核对清单与单餐修改各计一次，次数不是方案数。预留后失败也计次。
- 实时酒店与地图查询另设全站100次/日、每IP 20次/日及小时。
- 账本位于命名持久卷，容器重建后计数保留；文件损坏或不能写入则关闭实时调用，不回退到内存。
- 账本不保存原始IP、录音、图片或需求文本。服务端凭据、账本及证书不得提交。
- 主机vnstat持久统计eth0，当月收发总量达到150GiB或统计失效时暂停本项目容器。每5分钟检查，统计每分钟写入；保留免费流量余量。本机统计不代替云平台账单。
- 达到限额时仍可使用固定示例价格计算、手动填写和已收录餐饮资料；实时查询受限，主机流量保护触发时暂停整个网站。
- 不运行 docker compose down -v，避免删除持久计数和证书。
- 当前为单实例比赛演示方案，不能直接扩容为多个独立账本实例。
- `GET /api/quota` 只读展示访客每小时/每日、全站每日剩余和北京时间重置时刻，不预留额度，不返回IP或账本摘要。账本异常或备用后端无只读能力时显示不可用。
- 公共酒店/附近查询缓存5分钟、路线30分钟、坐标24小时；附近查询不跨北京时间日期复用。相同并发请求合并，失败不缓存，命中前仍检查访问开关与输入；缓存命中不重复扣源查询次数。模型与个人输入不缓存。

## 其他复现方式

根目录 compose.yaml 为自备域名的Caddy方案；中国内地公开网站还需核查备案。deploy/render-free.yaml 与 deploy/supabase-quota.sql 是备用免费托管配置，本项目没有在这些平台创建服务，不需要为当前方案登录这些平台。

## 页面与本地复现

页面支持逐日早餐、整体套餐支出、三餐选店、锁定、逐项确认、餐券条件、差异预览和撤回。本次反馈用于后续午晚餐同档候选排序，实付不修改菜单价或预算。图片卡与只读链接均在浏览器生成；只读页不调用模型或地图接口。

本地需要 Node.js 20+ 与 Python 3 执行完整测试，运行 `npm test`。应用没有 npm 运行时依赖，实时酒店查询另需已固定版本的 FlyAI CLI；Dockerfile 包含运行所需模块和资料。服务健康端点为 `/api/health`。部署更新必须保留现有环境配置、限额持久卷与证书。
