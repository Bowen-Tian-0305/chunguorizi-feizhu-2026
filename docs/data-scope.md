# 数据范围与时效

杭州是深度示范城市，全国城市选择不代表全国都有同等深度的数据。

| 集合 | 数量 | 用途及限制 |
| --- | --- | --- |
| 酒店深度资料 | 20 家 | 餐厅、餐次及权益线索，仍需核对当前商品 |
| 酒店公开早餐政策 | 25 家、33 条政策 | 采集时点的收费与时段，不能代替本次商品条款 |
| 酒店官网早餐补充 | 6 家 | 官网形式、时段、单买价及亲子条件；有冲突时提醒 |
| 具体分店早餐资料 | 3 家 | 指南可核到的地址与菜品；当天供应及过敏原需询问 |
| 外部专题门店 | 59 家 | 44 家来自同一餐饮集团，不能当作全城代表性样本 |
| 杭州餐馆资料 | 216 家 | 221 条原始记录中去掉 4 对重复与 1 家暂停营业门店；176 家核到地址，13 家有历史早餐证据 |

集合之间存在重叠，不可相加作为杭州酒店或餐馆总量。公开榜单页面能读到的条目不等于 App 完整榜单。2025 年的早餐营业线索不能保证 2026 年入住当天营业。

数据保留原始来源网址和采集日期。界面用“网络公开酒店政策资料”等通用名称展示第三方信息，不把第三方平台政策当作酒店官网承诺。坐标图与实时路线查询只负责位置和通行信息。

`scripts/` 中的采集打包脚本依赖本仓库之外的原始 CSV；运行应用无需执行这些脚本，仓库已包含可用 JSON。
