# 公开文件与隐私说明

检查日期：2026-10-23。范围为公开源码、JSON、文档、截图及演示视频。模式扫描和人工检查没有发现参赛者凭据或私人订单信息；该结论仅限已检查的交付范围。

## 公开内容

- 源码与数据保留真实来源、采集日期及适用范围；公开门店资料不含参赛者私人联系方式。
- 飞猪商品截图只展示公开酒店、房型、日期、价格与权益，不含姓名、手机号、订单号或付款信息。
- 演示使用公开页面、示例房价和合成测试语音；没有真实个人订单、用户录音、控制台页面或其他聊天。
- 首页截图为公开体验地址的实际页面。视频元数据没有个人名称、定位或本机路径。
- 投稿作者使用公开GitHub ID署名，不附私人邮箱、电话或收货地址。

## 输入与保存

- 录音、需求与截图经服务端处理，原始输入不在本服务持久保存。
- 本次截图预览只留在浏览器内；删除、更换或离开页面时释放，不写入浏览器持久存储。
- 个人餐馆星级和笔记只存当前浏览器；本次逐餐反馈只在浏览器会话中保留。实付记录用于回顾，不自动成为菜单报价。
- 图片分享卡和只读方案链接由浏览器生成。只读链接包含用户预览的酒店、日期、同行人数、逐餐与费用范围，内容位于 URL 片段，不在服务端保存；任何持有链接的人都可查看或转发。截图、录音、私人笔记和原始报价簿不进入分享快照。
- 单餐 AI 修改仅发送本次修改要求、目标餐次与白名单候选摘要，不发送私人笔记、原始订单、录音或完整浏览器状态。
- 限额账本只保存日期、IP的HMAC摘要与次数，不保存原始IP或输入内容。
- 剩余次数接口不扣次，不返回访客IP、HMAC摘要、盐或账本原文。

## 配置与交付

- 实际密钥、部署私钥、登录配置、`.env`、运行账本和证书不进入公开仓库与源码包；`.env.example`密钥字段为空。
- 发布包从明确的Git提交导出，扫描密钥、AccessKey、GitHub Token、私钥标记和参赛者本机路径。
- 备用数据库限额配置只允许服务端预留额度；数据库凭据和哈希密钥不发布。当前公开服务采用单实例ECS持久卷。
- 数据中的来源链接可能含公开文章签名，作为真实出处保留；不会把它们当作账号授权凭据。
