## 技术结果

- 主片 **72.000 秒**；**1920×1080、30fps、2160 帧**；H.264 / yuvj420p。
- AAC 立体声，48 kHz；正式原创配乐与 7 个原创合成音效，无旁白。
- 综合响度 **−16.0 LUFS**，真峰 **−2.5 dBTP**；未检出 `−45dB / 0.7s` 以上长静音。
- `blackdetect=d=0.15:pix_th=0.02` 未检出黑段；完整解码无错误。
- SRT 共 10 段，首段从 00:00 开始，末段止于 01:12，无重叠或倒置；本轮未改字幕时间或文本。
- 已重新渲染整片并检查最终抽帧：片尾仅保留品牌、口号、网址和开放信息；全部画面无“候选 / 临时 / 待替换”制作状态字样。
- 操作区域平均像素差：早餐 **16.340**、改餐 **58.411**、分享 **24.581**；均通过动态阈值，并另经看图确认动作。
- 详细数据：`assets/validation-summary.json` 与 `assets/validation/checksums.sha256`；完整命令和响度日志由 `src/verify.py` 在本地生成，不进入公开仓库。

## 真实 3D 片头预览

先输出并查看 `opening-3d-8s.mp4`，时长 **8.000 秒**，含有声音轨。按每 **0.5 秒**从实际预览导出 16 帧，接触表为 `assets/validation/opening-3d-contact.jpg`。

逐帧可见：价格牌具有厚度和投影；3 秒后价格牌在三维空间旋转退让；陶瓷碗及面条逐渐长成；日期牌从空间两侧归位；真实首页最后升起并由相机推进。0–3 秒已同时出现 ¥1200 / ¥1440、¥240 和“酒店早餐只吃 1 次”，冲突无需等待片头后段。

工程验证入口为 `src/opening3d.js`，本地依赖 **three@0.160.1**。自动检查确认源码包含并实际使用：

- `WebGLRenderer`、`PerspectiveCamera`
- `ExtrudeGeometry` 厚价格牌/日期牌
- `LatheGeometry` 陶瓷碗、`TubeGeometry` 面条
- 暖色灯光、`PCFSoftShadowMap` 实体阴影、`ACESFilmicToneMapping`

这不是 Canvas 2D `rotate/scale/shadow` 伪 3D。渲染按绝对时间确定，纹理和几何只在初始化时创建。
