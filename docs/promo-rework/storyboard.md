# 镜头与声音方案

## 视觉设计

- **色彩与材质**：深绿 `#17352e`、暖白 `#f7f2e8`、朱红 `#b65335`，辅以木桌、陶瓷、纸张与暖色窗光，延续网站而非使用数据宇宙或粒子模板。
- **3D 空间**：Three.js 透视相机、真实网格、粗糙度材质、半球光与方向光、软阴影、雾和 Bokeh 景深。酒店体块遮挡餐券，碗与卡片有前后关系；相机连续环绕、下推和升高。
- **收拢动作**：散落物体沿各自路径对齐到日期计划；路线曲线连接酒店与三餐。最后计划卡承载当前首页的真实截图纹理，翻转正对镜头并推满画面，与下一段真实录屏做 0.45 秒匹配淡化。
- **网页切换**：录屏保持原始像素，仅裁切、缩放和加外层画框。点击有克制的朱红焦点圈；镜头用慢推、局部平移、卡片滑动和匹配切。转场 0.45 秒，关键点击后至少停留 1.2 秒。
- **字幕**：底部独立深绿半透明字幕条，单条短句；网页关键内容置于画面中上部，避开字幕。示例标签与摄影署名始终不被字幕覆盖。

## 声音设计

- **配音**：先以 macOS 系统 `Eddy (中文（中国大陆）)`、`Flo (中文（中国大陆）)` 等生成同文案短试听，选择更自然温暖的一档；不使用 Tingting，不调用百炼或付费语音。逐镜短句生成，按语义停顿，不机械匀速念整篇。
- **配乐**：原创脚本合成，72 BPM 左右的轻木琴/拨弦、柔和和弦与极轻刷声；3D 段较疏，网页段略稳定，片尾 2 秒淡出。
- **音效**：自制纸张滑动、陶瓷轻碰与低音收拢提示，只在收拢、预览采用和分享切换出现。
- **混音**：旁白优先，音乐在旁白时自动压低；目标约 -16 LUFS、true peak 不高于 -1.5 dBTP，无削波、无突然截断。片头保留短环境起音，片尾完整收束。
- **字幕来源**：SRT 与烧录字幕均从实际旁白分段时间轴生成，确保一致。

## 制作顺序

1. 录制当前页面与首页 3D 卡纹理，保存功能状态报告。
2. 渲染 480+ 帧真实 WebGL 开场并编码。
3. 生成试听、确定声音，再按镜头录制旁白和原创音轨。
4. 以统一时间轴合成转场、字幕与混音。
5. 自动检测规格、黑帧、静音、响度、字幕；抽首中尾帧并完整播放成片复核。
