## 表达边界

- 单餐段使用真实手动换店，不发起也不伪造 AI 响应。
- 步行时间只呈现页面当次真实查询；方位图不称为街道地图。
- 不声称自动确认菜单、营业、忌口或过敏安全；未知项保留。
- 只读快照不是实时多人协作；持有链接者可查看和转发。
- 公网地址只作片尾入口，当前开放等待状态不在片中额外承诺。
