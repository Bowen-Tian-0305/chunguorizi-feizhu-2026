# 素材、工具与许可

## 真实页面与数据

- 页面：`http://127.0.0.1:4186/`，通过用户提供的仅本机 SSH 隧道访问当前 v1.3.1 最终版。成片不展示该本地地址。
- 页面操作：文字输入、截图示例展开、示例方案、A/B 条件、早餐日期、费用比较、杭州餐饮、附近路线、手动单餐换店与预览、手机端、只读分享。scene04 的 AI 旁白对应 README 已核实的百炼理解、转写与截图提取能力；本段录屏未发起 AI 调用，金额计算由本地代码完成。
- 示例输入：两晚 A ¥1200 / B ¥1440、两位成人、使用一次酒店早餐、外出早餐预算 ¥35/成人。均不是实时报价或全家最终价。
- 片儿川摄影由页面原样展示，署名 `N509FZ / CC BY-SA 4.0`；来源与许可页见页面链接及项目 `docs/image-credits.md`。

## 三维与制作工具

- Three.js 0.180.0，MIT License。酒店、碗、餐券、日期卡、路线、灯光、材质和镜头均由 `src/scene-3d.html` 与 `src/render-3d.mjs` 原创构建。
- Playwright 1.64.1，Apache-2.0，用于真实页面录制和 WebGL 逐帧渲染。
- FFmpeg（本机安装）用于编码、转场与混音；Pillow / NumPy 用于原创图形和声音合成。

## 配音、音乐与音效

- 已用同一短文案试听 macOS 系统自带 `Eddy (中文（中国大陆）)`、`Flo (中文（中国大陆）)`、`Reed (中文（中国大陆）)` 三档声音，最终选 Eddy；逐镜语速 182–190，按短语留 0.18 秒停顿，仅少数镜头微调时长。实际试听与最终选型在 `validation.md` 记录。不使用 Tingting，不模仿真实人物，不调用百炼或新增付费语音服务。Apple 系统声音随操作系统提供，成片为原创脚本的合成朗读；不重新分发声音模型。
- 配乐、纸张/陶瓷提示音及转场音均由 `src/make_audio.py` 原创合成，无外部采样。
- 中文字体使用 macOS 系统 `Hiragino Sans GB`，仅用于本片图形与字幕渲染，不分发字体文件。
